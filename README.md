𝓗ᴇʀ 𝓛ᴏʀᴇ: ғʀᴏᴍ ᴀ ʏᴏᴜɴɢ ᴀɢᴇ, ᴢᴀᴛᴀɴɴᴀ ʜᴀs ᴀʟᴡᴀʏs ʙᴇᴇɴ ᴘᴀssɪᴏɴᴀᴛᴇ ᴀʙᴏᴜᴛ ʙᴏᴏᴋs, ᴍᴀɢɪᴄ, ᴄᴜʀsᴇs, ᴀɴᴅ ᴠᴏᴏᴅᴏᴏ; ʜᴇʀ ᴍᴏᴛʜᴇʀ ᴍᴇᴀɴᴛ ᴛʜᴇ ᴡᴏʀʟᴅ ᴛᴏ ʜᴇʀ, ᴄᴏɴsᴛᴀɴᴛʟʏ ᴘʀᴏᴠɪᴅɪɴɢ ɴᴇᴡ ʙᴏᴏᴋs ғᴏʀ ʜᴇʀ ᴛᴏ sᴛᴜᴅʏ ᴀɴᴅ sᴀᴛɪsғʏ ʜᴇʀ ᴄᴜʀɪᴏsɪᴛʏ. ᴜɴғᴏʀᴛᴜɴᴀᴛᴇʟʏ, ʜᴇʀ ғᴀᴛʜᴇʀ ғᴀɪʟᴇᴅ ᴛᴏ ʀᴇᴄᴏɢɴɪᴢᴇ ʜᴇʀ ᴅᴀᴜɢʜᴛᴇʀ's ɢɪғᴛs, ᴅɪsᴍɪssɪɴɢ ᴛʜᴇᴍ—ᴀʟᴏɴɢ ᴡɪᴛʜ ᴍᴀɢɪᴄ ᴀɴᴅ ᴄᴜʀsᴇs—ᴀs ɴᴏɴsᴇɴsᴇ. ʙʟᴀᴍɪɴɢ ʜɪs ᴡɪғᴇ, ʜᴇ ᴀᴛᴛᴇᴍᴘᴛᴇᴅ ᴛᴏ ᴋɪʟʟ ʜᴇʀ ᴏɴᴇ ᴅᴀʏ, ʙᴜᴛ ᴢᴀᴛᴀɴɴᴀ ᴀʀʀɪᴠᴇᴅ ᴊᴜsᴛ ɪɴ ᴛɪᴍᴇ ᴛᴏ sᴀᴠᴇ ʜᴇʀ ᴍᴏᴛʜᴇʀ ᴡɪᴛʜ ᴀ ʟᴇᴛʜᴀʟ sᴘᴇʟʟ sʜᴇ ʜᴀᴅ ᴅɪsᴄᴏᴠᴇʀᴇᴅ sʜᴇ ᴄᴏᴜʟᴅ ᴄᴀsᴛ ᴇɴᴛɪʀᴇʟʏ ᴏɴ ʜᴇʀ ᴏᴡɴ. ᴅᴇᴇᴘʟʏ ɢʀᴀᴛᴇғᴜʟ, ʜᴇʀ ᴍᴏᴛʜᴇʀ ᴅᴇᴄɪᴅᴇᴅ ᴛᴏ sᴇɴᴅ ʜᴇʀ ᴛᴏ ɴɪɢʜᴛ ʀᴀᴠᴇɴ ᴄᴏʟʟᴇɢᴇ; ᴀʟᴛʜᴏᴜɢʜ ɪᴛ ᴡᴀs ᴀɴ ᴀʟʟ-ʙᴏʏs sᴄʜᴏᴏʟ, sʜᴇ ᴘᴀɪᴅ ᴀ ʜᴇғᴛʏ sᴜᴍ ᴛᴏ sᴇᴄᴜʀᴇ ᴢᴀᴛᴀɴɴᴀ's ᴀᴅᴍɪssɪᴏɴ, ᴀɴᴅ ᴄʀᴏᴡʟᴇʏ—ɴᴀᴛᴜʀᴀʟʟʏ—ᴀᴄᴄᴇᴘᴛᴇᴅ.
